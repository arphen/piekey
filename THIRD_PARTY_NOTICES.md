# Third-party notices

Fretboard Focus Lab includes the following third-party software and font data. Their original licenses and copyright notices remain in effect; the project’s AGPL-3.0-only license does not replace these terms. Keep this index and the linked full texts with redistributed builds and source.

This inventory covers every one of the 21 runtime package entries in `package-lock.json`, their identified embedded attributions, Vite’s build-generated browser helpers, VexFlow font data, and the five font families requested from Google Fonts. It is not an inventory of all development tools installed by npm.

All npm license texts were copied unchanged from the exact versioned tarballs below after checking each archive against the lockfile integrity value. Embedded license comments are retained as excerpts with their original wording. Font and additional upstream license texts are copied unchanged from the pinned sources below. File hashes, archive member names, revisions and download URLs are recorded in [the machine-readable inventory](notices/inventory.json).

## VexFlow music fonts and text metrics

VexFlow 4.2.5 includes font outlines and text metrics in JavaScript. The following licenses come from the same VexFlow source revision reported by that exact npm release: `67d49027443341578f2979fef3fd305d2a9ddf7a`. This keeps the original bundled notices and copyright years rather than substituting licenses from newer font releases.

The font named Gonville in this VexFlow release uses GonvilleSmufl outlines. Both its OFL notice and the original Gonville provenance are retained. Petaluma’s license also covers the included PetalumaScript text data; Roboto Slab’s package-matching Apache license is retained for its text metrics. VexFlow’s own custom glyph code is covered by its MIT license above.

OFL font data remains under the SIL Open Font License 1.1, including its Reserved Font Name conditions. It is not relicensed under the application’s AGPL. No standalone font binaries were copied into this notices collection. VexFlow’s upstream GonvilleSmufl license file ends at the termination clause; it is preserved unchanged, alongside a [complete OFL-1.1 text](notices/fonts/OFL-1.1.txt) copied verbatim from the license body shipped with Bravura in that same VexFlow revision.
